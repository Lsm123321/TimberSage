# 智筑云览（TimberSage）作品介绍

> **作品全称**：智筑云览 —— 基于智能技术的 3D 古建筑展示平台
> **技术栈**：Vue 3 + Three.js + ECharts ／ Spring Boot 3.2 + Java 17 + Spring Security(JWT) ／ MySQL 8 + Redis + MinIO ／ DeepSeek + 智谱 AI
> **成果状态**：已完成全栈开发并上线运行（HTTPS 域名访问，Docker Compose 云服务器部署）

---

## 一、作品定位

本作品是一个面向古建筑数字化展示与文化科普的 **Web 端 3D 展示与智能导览平台**。平台将古建筑三维模型在线呈现（旋转/缩放/线框/爆炸分解/材质调整），并深度融合大语言模型与语音 AI 能力，构建"**可看、可听、可问、可学**"的沉浸式数字展馆：

- **面向人群**：文博与古建爱好者、建筑/土木/历史专业师生、博物馆与景区线上展示场景；
- **核心场景**：古建筑 3D 沉浸浏览、AI 语音导览带自动运镜、构件级智能讲解、中国地图区域导览、AI 问答学习；
- **平台形态**：纯浏览器访问、免安装、移动端自适应，后台含完整的模型审核、用户权限、数据统计与内容运营体系。

## 二、作品创新

1. **LLM 驱动的"导演级"AI 语音导览（核心创新）**
   首创"AI 当导演、程序当摄影师"的导览范式：后端将模型元数据与构件清单组装为提示词，由 DeepSeek 生成结构化分章脚本（JSON 协议：旁白文案 + 相机坐标 + 高亮构件 + 动作编排），前端状态机逐章执行环绕 360°、爆炸分解、推近特写、拉远全景等自动运镜，配合 TTS 朗读与打字机字幕。脚本解析具备多层容错（剥除 Markdown 围栏、截取 JSON 数组、逐字段宽容解析），LLM 失败自动回退内置四章模板，服务不中断；脚本经 Redis 缓存 24 小时。

2. **构件级 AI 识别讲解**
   模型爆炸分解后可点选任意构件，AI 自动生成中文构件名称与简介，浮窗锚点实时跟随构件屏幕坐标并以 SVG 引导曲线指示——将榫卯、斗拱等传统营造技艺讲解精确到单个构件。

3. **程序化四季动态场景**
   纯代码实现（零外部图片资源）春·樱雨 / 夏·晴空 / 秋·斜阳 / 冬·落雪四套环境：Canvas 程序化绘制天空渐变、地面肌理、软云贴图，Three.js 粒子系统实现阵风粒子（花瓣/落叶/雪花/光斑）、落地堆积、贴地雾带，并辅以季节性生物点缀（粉蝶/蜻蜓/雁阵/寒鸦），太阳位置与色温随季节变化。

4. **AI 声音克隆专属导览员**
   管理员上传 3~30 秒人声样本，经智谱 GLM-TTS-Clone 克隆专属音色用于导览朗读；语音链路为"智谱 CogTTS 多音色 → 浏览器内置 speechSynthesis"的自动降级设计，保证弱网/未配 Key 时功能仍可用。

5. **SSE 流式 AI 问答学习闭环**
   全站 AI 问答浮窗流式输出（生产 Nginx 关闭代理缓冲保障流式），支持预设常见问题、回答点赞/点踩评价、问答历史、人工备注与 **AI 自动生成结构化学习笔记**。

## 三、实现方法

- **前端**（Vue 3 + Vite + Element Plus + Pinia + Tailwind v4，66 个源码文件、约 2.4 万行）：Three.js 加载 GLTF 模型实现查看器（线框切换、径向爆炸分解、OutlinePass 构件高亮、材质面板与云端方案保存）；核心逻辑沉淀为组合式函数——`useAiTour` 导览状态机、`useCameraFlight` 相机飞行/环绕运镜（easeInOut 缓动、用户拖拽自动中断）、`useSceneEnvironment` 四季环境、`useSpeech` TTS 三级降级抽象；LLM 输出的机位坐标经安全夹取（clampViewpoint）防止穿模。
- **后端**（Spring Boot 3.2 + Java 17，164 个源码文件、约 1.1 万行）：19 个 Controller 覆盖认证（JWT + 图形验证码）、模型管理与审核发布、评论/点赞/收藏、反馈体系、地图服务、统计报表；封装 DeepSeekClient 与智谱 CogTTS / GLM-TTS-Clone 客户端；MinIO 托管模型与缩略图（同源反代避免跨域）；Redis 缓存导览脚本与验证码；提供 Swagger 文档与旧接口兼容层。
- **数据**：MySQL 8，22 张业务表（用户权限、建筑与模型、互动、AI、反馈等五大分组），utf8mb4 字符集，JPA 实体即权威表结构。
- **权限体系**：游客 / user / contributor / admin 四级角色，user→contributor→admin 在线申请 + 管理员审批的晋级链路。
- **部署运维**：Docker Compose 一键编排 MySQL / Redis / MinIO / 前端 Nginx / 后端五服务，HTTPS 域名接入，配套离线镜像部署文档；全栈代码约 **3.5 万行**，文档齐全（README、数据库设计、AI 导览系统协议文档、部署指南、功能清单）。

## 四、成果状态

- **已完成**：用户端与管理后台全部功能开发完毕，前后端联调通过，管理后台含演示数据（66 个真实模型记录、近 30 天下载/问答等统计数据）；

## 六、应用价值

1. **文化传承价值**：为古建筑提供低成本、可交互的数字化展示窗口，让榫卯构造、构件体系等传统营造智慧以"看得懂、听得进"的方式触达公众，助力文化遗产活化传播。
2. **教育教学价值**：可直接服务于建筑史、建筑构造等课程——爆炸分解观察构件组合关系、AI 构件讲解替代人工答疑、AI 学习笔记辅助复习，形成"观摩—提问—总结"的教学闭环。
3. **行业应用价值**：为博物馆、景区、文保单位提供免安装的线上数字展厅方案；平台的三级角色 + 审核投稿机制支持众包共建模型库，具备持续扩充内容的运营能力。
4. **技术示范价值**：所沉淀的"LLM 结构化脚本 → 3D 引擎动作执行"导览范式，可迁移至工业设备培训、虚拟展厅、数字孪生讲解等更广泛的"大模型 + 三维交互"场景。
